# 报告结构

按实际材料填写；未知项注明验证办法，不交付空模板。

# 产品名称：机会评估与落地规划

日期、阶段、形态、市场/地区/语言及选择依据、调查范围和限制。

## 决策摘要
用简短表格给出：需求价值判断｜当前可做性｜总体难度与关键瓶颈｜建议开发/先验证/调整方向/暂缓｜结论依据与可信程度。另写最大风险、下一步及改变结论的条件，避免只给标签。

## 1. 产品任务与投入边界
谁在什么场景获得什么结果；时间、预算、技术、现有受众和维护能力；未知信息。

## 2. 动机比较、核心人群与痛点
先比较至少两个实质不同的动机假设，再给结论。不将候选写成已证实需求。

表格：候选人群/场景｜根本诉求｜触发事件与不解决后果｜当前投入及行为证据｜工具可改善环节｜付费主体与可触达性｜反证/未知。

用文字说明首要动机和人群、其他候选暂缓理由，以及推翻选择的证据。无法充分比较时说明缺口，仅给暂定人群和区分假设的验证方法。

对选中假设拆解：根本诉求 → 具体任务 → 操作障碍 → 对真实结果的影响。说明移除障碍是否足够、非软件方案是否有效。明确该动机如何改变核心功能、社媒承诺和付费理由，不止展示表格。

## 3. 竞争与切入机会
表格：方案及链接｜服务人群｜解决方式｜价格与限制｜不足及证据｜切换成本｜切入点。
说明替代方案、分发竞争、反证和差异化的可持续性。

## 4. 形态与功能
首版形态、核心用户路径、首次价值、复用理由。
表格：痛点｜功能｜改善机制｜首版/附加/暂缓｜验收信号｜工作量与依赖假设。
说明功能优先级、免费边界及付费价值的关系。

## 5. 核心用户与社媒获客
表格：渠道｜用户场景及依据｜内容方向及具体选题｜行动入口｜首次使用路径｜指标｜执行成本。
给出符合资源条件的首批用户获取步骤和渠道取舍理由。

## 6. 变现与经营条件
付费主体、动机、计费单位、模式、定价假设及来源。成本、依赖、投入范围与盈利条件；情景与预测分开。

## 7. 可做性与实施难度结论
明确回答：这个需求是否值得投入？以当前资源能否做成？最难在哪里？

表格：维度（开发、数据/外部依赖、获客转化、变现、运营维护）｜低/中/高/未知｜依据与资源假设｜关键难点｜降难度办法。

可做性结论：当前可做 / 满足条件后可做 / 当前不适合做 / 信息不足，列出必要前提、阻塞项和核查方式。

分别写演示原型与可上线首版的范围、关键工作项、工作量区间及估算依据；已知每周投入时给日历周期，外部等待单列。无法估算则说明信息缺口。给出保留核心价值的最简版本、继续投入条件与停止条件。

## 8. 最小验证计划
表格：风险假设｜目标对象与招募渠道｜实验步骤｜时间/预算上限｜指标及分母｜继续/调整/停止标准。
说明执行顺序及第一件事。

## 9. 待决事项与证据
待决定问题、未知项、改变结论的新证据；证据账本及链接、日期、信息类型和局限。
