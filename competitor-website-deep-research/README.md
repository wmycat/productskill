# 竞品网站深度调研

输入一个或多个竞品网站链接，输出中文深度调研报告，帮助判断是否值得做类似产品。

## 调用

```text
$competitor-website-deep-research
请调研这个竞品：https://example.com
重点分析目标人群、痛点、功能、付费点和我是否值得做。
```

可以只提供链接。需要指定市场、地区、产品形态或重点问题时直接补充；未说明的内容会根据网站信息提出假设。

报告默认生成 PDF，保存到 `output/pdf/竞品简称-竞品深度调研-YYYY-MM-DD.pdf`。也可以指定 Markdown、Word、聊天表格或其他格式。

## 研究范围

定位、目标人群、根本诉求与操作障碍、多动机比较、用户流程、功能、付费、反馈、竞争、获客、SEO、风险、可借鉴部分，以及需求价值、可做性和难度结论。必须包含人群与动机表、付费点表、竞品功能与机会表。

## 限制

只分析公开可访问内容，不绕过登录、付费墙、验证码或访问控制。无法访问的内容会标明。报告区分事实、推断和待验证假设。

## 安装

将整个文件夹放入 `~/.codex/skills/`；设置 `CODEX_HOME` 时放入其 `skills/` 目录。
