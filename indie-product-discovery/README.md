# 工具产品机会评估与落地规划

面向独立开发者的 Codex Skill，评估小程序、App 和网站工具想法，输出中文 Markdown 决策文档。

涵盖目标人群、痛点、竞品、核心和附加功能、社媒获客、变现成本与验证计划。允许得出暂缓结论，区分联网证据与假设。

## 可做性与难度结论
报告明确区分“值得做”和“当前能做成”。给出当前可做、满足条件后可做、当前不适合做或信息不足的结论，并分别评估开发、数据依赖、获客、变现和运营难度。包含原型/首版投入估算、关键瓶颈、降难度方案和继续/停止条件；依据不足时保留未知，不虚构成功率或精确工期。

## 市场规则
用户指定优先。未说明时，小程序默认国内，App 和网站默认海外；海外具体地区需进一步判断。

## 安装
将整个 `indie-product-discovery` 文件夹放入 `~/.codex/skills/`。设置了 `CODEX_HOME` 时放入其 `skills/` 目录。保留 SKILL.md、agents 和 references。安装后在新会话调用。

## 使用
```text
$indie-product-discovery
我想做一个帮助自由职业者整理客户修改意见的网站。
每周能投入 10 小时，预算有限，目前没有用户。
请评估是否值得做，输出产品决策文档。
```

也可明确指定市场，例如“分析面向国内的记账 App”。希望快速初稿时说明“基于假设直接分析”。

默认生成 `reports/产品简称-YYYY-MM-DD.md`，可指定路径或格式。

## 条件
需要能读取 Skill 的助手。市场核查需要联网工具，保存文档需要写入能力。不依赖其他自定义 Skill 或付费 API。无法联网时生成明确标注的假设版。不会自动发布营销内容、联系用户或收款。
