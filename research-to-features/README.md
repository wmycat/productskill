# 调研转功能清单

将市场调研或产品机会评估文档转为四列表格：**功能点、功能说明、优先级、UI建议**。

## 调用

```text
$research-to-features
根据这份市场调研文档，整理功能清单。
```

附上文档、粘贴正文或提供文件路径即可，无需另填问卷。支持此前 indie-product-discovery 的输出，也支持其他调研文档。

优先级默认 P0 首版必需、P1 后续增强、P2 暂缓；关键未知标为待验证。UI建议具体到页面入口、布局、控件及关键反馈。输出区分调研依据与补充建议。

默认保存为工作区 `reports/产品简称-功能清单-YYYY-MM-DD.md`。可要求只在对话显示。

## 安装

将整个 `research-to-features` 文件夹放入 `~/.codex/skills/`；设置了 `CODEX_HOME` 时放入其 `skills/` 目录，然后在新会话调用。不依赖其他自定义 Skill。读取附件或在线文档需要运行环境提供相应读取工具。
